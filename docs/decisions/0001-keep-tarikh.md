# 0001 Keep the Tarikh concept

**Status:** Accepted on 20 November 2026.

**Decision:** Tarikh stays: a desk for one Section 138 cheque-bounce matter. It reads three papers, finds the missing dates,
counts the statutory windows in code, drafts a brief in which every sentence cites a fact, and answers questions through an
agent that can only read that matter.

**Why:** Piyush chose it from the options and locked it. It uses every area of the AI-901 skills outline that Foundry covers:
information extraction, speech, text analysis, generative AI, an agent, and responsible AI. It has a real user and a real
cost of a mistake, which is what makes the design decisions defensible. What was wrong in v0 was design, finish and delivery.

**How it was decided:** Piyush answered "I agree, so start" to a plan whose step 3 recommended keeping it. He did not answer the
question directly. Read as yes.

**Cost if wrong:** Phases 1 to 4 would be redone for a new idea. Nothing built so far is lost.
