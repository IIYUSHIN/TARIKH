Every one of those cases began with four deadlines in a row, each counted from a date printed on a different paper. Miss one and the complaint can fail before it is heard. Tarikh exists so that never happens, and so that what follows in court moves faster.

01 · Read

Photograph the papers. Get the facts.

The cheque, the return memo, the notice and the postal receipt become fields. Each value shows where it was read and how sure the reading is. A date that no paper shows is asked for, never guessed.

  • Phone photos and scans in English and Hindi.
  • Every field traceable to a box on the original.

02 · Count

Dates are law, so a rule counts them. Not a model.

Drag any pin below. The four statutory windows move with it, counted by a tested rule engine that states its rule and its doubts. This is the real engine, running in your browser.

03 · Draft

Court-ready drafts, built from facts you can check.

Notice, complaint, the synopsis the Supreme Court now requires after the index, the affidavit of the accused’s contact details, applications under Sections 143A and 147. Every fact in the draft is marked by where it came from.

  • Nothing without a source. A sentence that no paper supports is removed before you see it.
  • You sign, it doesn’t. Drafts stay drafts until an advocate approves by name.

The directionWhat Tarikh does
A synopsis in a set format, right after the index of every complaintDrafts it from the traced facts, in that position.

How AI is used

A model reads. A rule counts. A person decides.

READS

AI turns paper into facts

Document reading, speech in English, Hindi and Punjabi, and masking of personal details before any model drafts.

COUNTS

Rules decide every date

No model ever produces a deadline. The engine is plain code with published tests and a public rule register.

DECIDES

An advocate approves

Nothing is filed or sent by Tarikh. Every approval is recorded with a name and a time.
