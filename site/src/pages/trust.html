Trust

Six principles, written as behaviour.

Microsoft’s responsible-AI principles are easy to agree with and easy to ignore. Here each one is a specific thing the desk does, and where in the product you can see it.

Fairness

It never scores a person.

The desk does not rank, rate or predict anyone. Parties appear exactly as the papers name them. There is no model for “likely to win” and none will be added.

Seen in: the brief, which holds only facts that trace to a paper.
Reliability and safety

Dates are counted, not generated.

A rule engine with written tests counts every date, so the same papers always give the same answer. A model that is unsure is not allowed to guess a date.

Seen in: the rule register, and the more than a hundred automated checks.
Privacy and security

Masked before a model reads it.

The client’s account passes a privacy step that hides names, numbers and addresses before any model sees it. Access to Azure uses your sign-in, not a key stored in the code.

Seen in: the security page.
Inclusiveness

The client speaks their own language.

The account can be given in English, Hindi or Punjabi. Every control works by keyboard, the focus is always visible, and no meaning rests on colour alone: each colour is also written as words.

Seen in: the long table, where every pin is a slider with a spoken date.
Transparency

Every fact shows its paper.

Each field links to the page and the spot it was read from. Each date states the rule behind it, and the rule register states how sure the rule is. Where a fact is on no paper, the desk says so.

Seen in: the trace step, and every footnote in the brief.
Accountability

A named person approves.

A brief stays a draft until an advocate types their name and confirms they checked it. The approval is written to an audit log. The desk files nothing and sends nothing.

Seen in: the approval box on the brief.

What we will not claim

Limits, stated plainly.

  • It is not legal advice.It is a tool that organises dates and papers for a qualified advocate.
  • It does not know every court’s calendar.Holidays and condonation of delay are left to the advocate.
  • Its legal sources are secondary for now.Primary texts are still to be checked and cited. The clocks page says which rules stand on what.
  • It is a student-built prototype.There are no customers, no testimonials and no usage figures on this site because there are none to show.
